# Basement

Game mechanics Zombie • Health • Crafting • Building • Fire • AI • Noise • Weather • Erosion • Electricity • Metagame • Helicopter

This article contains outdated/low-quality images . Reason: Finish adding images and replace existing images once official tools are available. Please help the PZwiki by uploading an improved/updated version of the image(s) found on this page.

Basement is an underground section of a building that can be explored by the player. They were first introduced as part of Build 42 with the upgraded engine allowing expansion both up and down. There are a number of predefined basements that will always generate as part of the world, these are built into the map itself, while the rest are generated randomly based on the map seed on creation. Predefined basements can be seen by using B42 Map .

The player currently cannot create their own basements. Destroying the walls of a basement and walking into the void will teleport the player back to ground level. Bug

### Random

The following basements spawn randomly for each world, determined by the world seed, and whether the building meets the requirements for the basement to spawn. Basement entrance locations are defined in the games code. Random basements can come in multiple shapes, and directions. Some basements have been recreated in both directions, while others share a shape but are furnished uniquely.
