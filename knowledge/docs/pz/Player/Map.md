# Map

Game mechanics Zombie • Health • Crafting • Building • Fire • AI • Noise • Weather • Erosion • Electricity • Metagame • Helicopter

The world map can be accessed by pressing M . By default, it only shows the places the player has already been to or found a map or a flier of, but enabling the All Known On Start setting in the In-game Map section in Custom Sandbox will make it display places that they've not visited yet. It can also be opened by clicking on the mini-map if it is enabled.

## Writing

The world map can be annotated the same way that handheld maps can be annotated.

### Add note/symbol
- **Action:** Add note/symbol
- **Description:** Requires any writing implement.
### Edit note/symbol
- **Action:** Edit note/symbol
- **Description:** Requires any writing implement and an eraser.
### Move note/symbol
- **Action:** Move note/symbol
- **Description:** Requires any writing implement and an eraser.
### Remove marking
- **Action:** Remove marking
- **Description:** Requires an eraser.

## Strategy

- The world map can be used to easily remember directions to certain places, or to take notes without the use of paper items.
- Currently, any annotations made on the world map will persist until they are erased, even if the character that made them dies and a new one is created.
- Currently, annotations cannot be transferred from a handheld map to the world map without the use of mods.
- It can be argued that the world map has made the handheld map items, other than annotated maps, obsolete in single player. The world map is always accessible, and does not add encumbrance to the character's inventory.

## Trivia

- The world map and mini-map were originally part of a mod by Eris, but were included in Build 41 as a full-fledged feature.
