# Phone numbers

Lore Businesses • Metagame • Outfit • Survivor • Knox Event • Knox Infection • Raleigh Outbreak • Randomized stories

The intent of this page is to gather information about the fictional phone numbers in Project Zomboid. These serve no purpose, other than lore.

It seems that in Project Zomboid , 943 is an area code for Knox Country , while in real life, 943 is an area code for Georgia state.

Except the emergency 911 number, all numbers uniformly use the 555 prefix, which is recommended for fictional use and was used in many North American television shows, films, video games, and other media.
